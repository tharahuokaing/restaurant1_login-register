# restaurant1_login-register
# ហួ កាំង 5 STAR — Restaurant 1 (Branch 1) Cyber POS

An ultra-modern, cyberpunk-themed Point of Sale (POS) and online ordering web application for **ហួ កាំង 5 Star (Branch 1)**. Built with high-performance CSS glassmorphism, responsive Khmer typography, and modular authentication modal systems.

## 🚀 Features

* **Cyberpunk HUD Aesthetic**: Neon glassmorphism interface styled with custom CSS system variables, ambient glowing grids, and real-time animation states.
* **Responsive Khmer Typography**: Integrated with Google Fonts (`Kantumruy Pro`) for crisp rendering across all screen resolutions and devices.
* **Interactive Authentication Modal**: Built-in modal dialog supporting seamless switching between **Login** (`ចូលប្រព័ន្ធ`) and **Register** (`ចុះឈ្មោះ`).
* **Category & Search Controls**: Real-time category filtering interface and search input tailored for handheld touch POS terminals and desktop displays.
* **Modular Codebase**: Clean separation of structure (`index.html`), presentation (`style.css`), and logic (`script.js`).

## 📁 Project Structure

├── index.html        # Main HTML structure and authentication modals
├── style.css         # Custom Cyberpunk design system & CSS variables
└── script.js         # Interactive DOM logic and authentication handlers

## 🛠️ Installation & Setup

1. **Clone or Download the Repository**:
Save all three files (`index.html`, `style.css`, and `script.js`) into the same folder directory.
2. **Run Locally**:
Simply open `index.html` in any modern web browser (Google Chrome, Mozilla Firefox, Safari, or Microsoft Edge).
3. **Development Preview**:
If using Visual Studio Code, you can open the project with the **Live Server** extension for real-time live reloading.
